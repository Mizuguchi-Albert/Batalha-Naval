# Batalha dos Piratas

Batalha naval com tema pirata para jogar com a família, direto no navegador.

**Jogar:** https://mizuguchi-albert.github.io/Batalha-Naval/

- **Mesmo aparelho:** dois capitães passando o aparelho a cada turno.
- **Dois aparelhos:** um capitão cria a sala e passa o código de 4 letras; o outro digita o código no seu aparelho. A conexão é direta entre os aparelhos (WebRTC via PeerJS) e cada frota fica só no aparelho do dono.
- Tiros de canhão animados, splash, explosões e navios que explodem e afundam no tabuleiro.
- Papagaio narrador e baú do tesouro para o vencedor.
- Arte em `arte/` (desenhada no Figma).

Para testar o modo de dois aparelhos em duas abas do mesmo navegador, abra o jogo com `#teste` no fim do endereço.
