# Batalha dos Piratas

Batalha naval com tema pirata para jogar com a família, direto no navegador.

**Jogar:** https://mizuguchi-albert.github.io/Batalha-Naval/

- Dois capitães no mesmo aparelho, passando a vez.
- Tiros de canhão animados, splash, explosões e navios que afundam no tabuleiro.
- Papagaio narrador e baú do tesouro para o vencedor.

Próximos passos: modo em dois aparelhos, música e efeitos sonoros, arte nova.
